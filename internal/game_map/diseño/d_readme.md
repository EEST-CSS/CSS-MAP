# Colores y Propiedades de los Props
Veremos como estan definidas las propiedades de los props através de los colores para el diseño del gameplay en "papel"

## Propiedades de los Props
Cada prop tiene ciertas propiedades que vamos a resumir con letras
- R: Rompible
- S: Wallbang
- V: Visible através
- N: No
> [!TIP]
> <details>
> <summary>Ejemplos</summary>
>
> NR = No Rompible
> SNR = Wallbangeable y No Visible
> NVNSNR = No Visible, No Wallbangeable, No Rompible
> </details>

## Colores
